# Prova foto posturali

Pagina di test: guida alla foto posturale (fronte, lati, spalle), controllo della qualità, volto oscurato, punti e linee di riferimento.
Tutto avviene nel browser del telefono: nessuna foto viene inviata o salvata online.

Riconoscimento del corpo: MediaPipe Pose (Google, licenza Apache 2.0), file inclusi nel repository.
